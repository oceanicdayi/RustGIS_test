# 教師手冊：120 分鐘
## 0–20 分：WebGIS
開啟 https://web.rustgis.app ，建立空白地圖，下載並匯入 data/synthetic_earthquakes.geojson。使用 Data/Home 的資料載入功能（版本介面可能改變）。查看屬性表：mag、depth_km、source。確認 6 筆，EPSG:4326 經度在前。
## 20–40 分：符號設計
Style 中選比例符號，以 mag 控制大小；另做深度分級色彩。規模不是線性釋能，圖符只是編碼。比較兩種圖例的閱讀差異。
## 40–65 分：POE
Predict：畫出 30、50、100 km 環域預期；Observe：Analyze > Buffer 選地震圖層、公里單位，逐次執行並比較重疊。Explain：為何環域不能當作震度、預警範圍或風險？
## 65–90 分：Notebook
開啟 README 的 Colab 連結。執行 World Atlas、合成資料、USGS 2024-04 UTC 目錄查詢。確認資料來源及事件數；查詢結果可更新，保存原始查詢 URL 與查詢時間。若網路中斷，用合成資料完成。
## 90–110 分：AI 與 CER
提示詞：根據已載入資料提出東西部地震分布的可檢驗主張；列出命令參數與不確定性，不要捏造事件數。學生先預測，再執行，保存 AI 對話與指令證據。比較不同深度與規模門檻造成的結果差異。
## 110–120 分：提交
地圖 PNG、GeoJSON、研究問題、CER 段落、AI 操作紀錄。評量 100 分：資料與 CRS 正確 25、地圖與圖例 25、證據與推理 30、可重現性及 AI 驗證 20。
延伸：下載真實測站資料後做 Near；IDW 只能插值具有物理意義的連續測值，不能將震央規模直接插值成震度。正式防災應使用官方資訊。
